# M.iTech Website

نسخة أولى مجانية لموقع M.iTech.

## التشغيل
افتح `index.html` مباشرة بالمتصفح.

## النشر المجاني على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع `index.html` و`style.css` و`script.js`.
3. من Settings → Pages اختر Branch: `main`.
4. احفظ وانتظر رابط الموقع.

## التعديلات القادمة المقترحة
- ربط قاعدة بيانات أسعار الهواتف.
- صفحة تفاصيل لكل جهاز.
- مقارنة جهازين.
- لوحة تحكم لإضافة الأسعار والمراجعات.
- ربط Google Analytics.
- ربط دومين خاص مثل mitech.tech.
